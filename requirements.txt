6. INSTALLATION INSTRUCTIONS
═══════════════════════════════════════════════════════════════════════════

STEP 1: Create requirements.txt (if not downloaded)
─────────────────────────────────────────────────────

Create file: requirements.txt
Content:

flask==2.3.0
flask-cors==4.0.0
langchain==0.0.300
langchain-community==0.0.1
langchain-huggingface==0.0.1
chromadb==0.4.0
huggingface-hub==0.18.0
sentence-transformers==2.2.2
pypdf==3.17.1
python-dotenv==1.0.0
requests==2.31.0


STEP 2: Install Python Packages
────────────────────────────────

Option A - Using requirements.txt (RECOMMENDED):
  pip install -r requirements.txt

Option B - Install individual packages:
  pip install flask==2.3.0
  pip install flask-cors==4.0.0
  pip install langchain==0.0.300
  pip install langchain-community==0.0.1
  pip install langchain-huggingface==0.0.1
  pip install chromadb==0.4.0
  pip install huggingface-hub==0.18.0
  pip install sentence-transformers==2.2.2
  pip install pypdf==3.17.1
  pip install python-dotenv==1.0.0
  pip install requests==2.31.0

Option C - Quick install (all at once):
  pip install flask flask-cors langchain langchain-community langchain-huggingface chromadb huggingface-hub sentence-transformers pypdf python-dotenv requests


STEP 3: Install Node.js Packages (Frontend)
──────────────────────────────────────────

In your project folder:
  npm install

This installs React, Vite, and all dependencies from package.json


STEP 4: Verify Installation
───────────────────────────

Python:
  pip list              # Shows all installed packages
  python -c "import flask; print(flask.__version__)"
  python -c "import langchain; print('LangChain OK')"

Node.js:
  npm list              # Shows all installed packages
  npm list -g           # Shows global packages

12. TROUBLESHOOTING INSTALLATION
═══════════════════════════════════════════════════════════════════════════

Problem: "ModuleNotFoundError: No module named 'flask'"
Solution: pip install flask

Problem: "pip: command not found"
Solution: Use python -m pip install package_name

Problem: "npm: command not found"
Solution: Install Node.js from https://nodejs.org/

Problem: "Port 5000 already in use"
Solution: Kill process using port 5000:
  Windows: netstat -ano | findstr :5000, then taskkill /PID xxxx
  macOS/Linux: lsof -i :5000, then kill -9 <PID>

Problem: "HUGGINGFACE_API_KEY not found"
Solution: Create .env file with: HUGGINGFACE_API_KEY=your_key

Problem: "chromadb connection error"
Solution: Make sure chroma_db/ folder exists and has permissions
